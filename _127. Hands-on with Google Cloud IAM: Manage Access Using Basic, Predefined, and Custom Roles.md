# Bước 06: Custom Role — Stop và Start VM

## Bước 06-01: Tạo Custom Role

Truy cập:

**IAM → Roles → CREATE ROLE**

Thiết lập:

* **Title:** Custom Role Start Stop VM
* **ID:** customRoleStartStopVM101

Thêm các permission:

* **compute.instances.start**
* **compute.instances.stop**

Nhấn **CREATE**

![](https://media2.dev.to/dynamic/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fvxhp1w70ayldrkla1c2e.png)

Lưu ý:
Tên permission chính xác là **compute.instances.start** và **compute.instances.stop** (cần nhập đúng chuỗi permission khi thêm).

---

## Bước 06-02: Thêm Principal với Custom Role

Truy cập:

**IAM & Admin → IAM → GRANT ACCESS**

Thực hiện:

* **Add Principal:** [gcpuser08@gmail.com](mailto:gcpuser08@gmail.com)
* **Select Role:** Compute Viewer
* **Select Role:** Custom Role Start Stop VM (role tùy chỉnh vừa tạo)

Nhấn **SAVE**
